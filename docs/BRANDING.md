# SPECTRE branding

SPECTRE's emblem is a striped red pyramid with an eye whose iris is a globe,
over the wordmark **SPECTRE**, the subtitle **GLOBAL INTELLIGENCE DASHBOARD**
and the sub-line **REAL-TIME • ANALYZE • PREDICT • GLOBAL INSIGHTS**.

Every product name, tagline and brand colour the code uses comes from
[`src/branding.js`](../src/branding.js); this page covers the image files and
how to use them.

## Rules

- **Dark backgrounds only.** The transparent PNGs are luminance-keyed: they are
  correct on black or near-black and wrong on anything light. On a light
  surface (a light-mode GitHub page, a slide, print), use
  `docs/brand/spectre-logo-source.png`, or the social image, which carry their
  own black.
- **Don't recolour, stretch, crop, rotate or outline** the emblem, and don't add
  drop shadows beyond the faint red glow the header already has.
- **Minimum sizes:** the full lockup at least 160 px wide; the mark at least
  24 px wide. Below that, use the favicon crop, which was drawn for small
  sizes.
- **Words are text.** The tagline and sub-line in the UI are real, translated
  text (`BRANDING.tagline`, `BRANDING.subline`), for accessibility and
  scaling. Only the boot overlay uses the raster subtitle and sub-line, as part
  of the lockup.
- **The sub-line is a slogan, not a feature list.** In prose, describe only
  what exists: satellite pass prediction (SGP4 from orbital elements,
  `src/data/satellitePass.js`) and forecasts that come from a named source
  (cyclone tracks, weather). Don't claim SPECTRE predicts events.
- **The glitch is decoration on logo layers only.** It never touches data,
  charts, chat text or tables. Alerts keep their own icon, label and pulse and
  never reuse the glitch classes (`.sp-part`, `.sp-ghost`, `.is-glitch`): red
  already means both brand and danger.
- **Status is never colour alone.** Boot rows pair a glyph with a word:
  `●` ONLINE, `◐` DEGRADED, `✕` OFFLINE / NO RESPONSE.

## Colours

Measured from the emblem; tokens in [`src/theme/spectre.css`](../src/theme/spectre.css)
and `BRANDING.colors`.

| Token | Value | Use | Contrast on `#000` |
|---|---|---|---|
| `--sp-red` | `#F80000` | text, icons, active states | 4.99:1 (AA); 4.67:1 on `--sp-surface` |
| `--sp-red-on-raised` | `#FF1A1A` | red text on `--sp-surface-2` and on red tints (active controls, the voice dock), where `#F80000` drops to 4.44–4.46:1 | 5.41:1; 4.80:1 on those surfaces |
| `--sp-red-deep` | `#C80000` | fills and borders only, never small text | 3.46:1; white on it is 6.08:1 |
| emblem grey | `#C8C8C8` | the wordmark's grey (raster only) | — |

Before the emblem, the reds were `#FF2800` and `#D40000`. To go back, restore
those two values in `BRANDING.colors` and the three lines marked in
`src/theme/spectre.css`, then run `node scripts/generate-spectre-recolor.mjs`.

## Boot overlay and brand glitch

[`src/boot/`](../src/boot/) and [`src/theme/spectre-boot.css`](../src/theme/spectre-boot.css):
the lockup assembles on black with four status rows fed by real checks, then
removes itself. Settings: Display ▸ Boot animation (Full / Short / Off) and
Brand glitch (On / Off); `?boot=off|short|full` overrides; embedded views and
`prefers-reduced-motion` get no motion. Smoke test: `npm run qa:spectre-boot`.
